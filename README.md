# 🍆 PisunBot — Класична гра для друзів та груп

Максимально простий, чистий та зрозумілий Telegram-бот без зайвої «каші», складних меню та довгих описів. Тільки чисті цифри, дуелі, казино та таблиця лідерів.

---

## 🎮 Як працює бот:

1. **🍆 Кнопка «Ростити»:**
   - Працює раз на 24 години.
   - Коротка відповідь: на скільки см змінився розмір та скільки стало.
2. **📏 Кнопка «Мій розмір»:**
   - Поточна довжина та таймер до наступної спроби.
3. **🎰 Кнопка «Казино (5 см)»:**
   - Кидок 3D-кубика в Telegram. Випало 4, 5, 6 — виграш, 1, 2, 3 — програш.
4. **⚔️ Дуель у групах:**
   - Відповідь на повідомлення друга словом: `дуель 5`.
5. **🏆 Кнопка «Топ 10»:**
   - Рейтинг лідерів чату за розміром з медалями 🥇 🥈 🥉.

---

## ☁️ Хмарна база даних (Neon.tech PostgreSQL)

Дані не стираються при перезапусках Render.com.
Просто додайте `DATABASE_URL` у змінні оточення (або залиште порожнім для локального SQLite).
