# 🍆 PisunBot — Легендарна гра для друзів та груп

Повноцінний Telegram-бот із грою вимірювання, випадковими подіями, титулами, візуальною шкалою, дуелями між друзями та таблицею лідерів. Повністю оптимізований для **безкоштовної цілодобової роботи 24/7 на Render.com**!

---

## 🎮 Що вміє бот:
1. **🍆 Кнопка «Ростити»:**
   - Можна крутити раз на 24 години.
   - Випадкові події (як приємні бонуси `+10 см`, так і кумедні факапи `-5 см`).
   - Показує візуальний агрегат `8====D` та титул (від *«🤏 Малишок»* до *«🛸 Міжгалактичний Дрючок»*).
2. **📏 Кнопка «Мій розмір»:**
   - Повна статистика, поточна довжина, таймер зворотного відліку до наступної спроби та історія дуелей.
3. **🏆 Кнопка «Топ гравців»:**
   - Таблиця лідерів (у групі показує топ учасників цієї групи з медалями 🥇 🥈 🥉).
4. **⚔️ Команда `/duel` у групах:**
   - Відповідаєш (Reply) на повідомлення будь-якого друга в групі командою `/duel`.
   - Бот кидає кубики `🎲` — переможець відриває кілька сантиметрів у друга і забирає собі!

## ☁️ Як запустити 24/7 на Render.com (Покрокова інструкція)

### Крок 1. Завантажити файли на GitHub (1 хвилина)
1. Зайдіть на [github.com](https://github.com) і увійдіть у свій акаунт.
2. Натисніть зелену кнопку **New** (створити репозиторій).
3. Назвіть його, наприклад, `pisun-bot`, поставте перемикач **Public** і натисніть **Create repository**.
4. На сторінці, що відкриється, натисніть посилання **uploading an existing file** (завантажити файли).
5. Перетягніть мишкою такі файли з папки `C:\Users\TUF\Desktop\PisunBot`:
   - `bot.py`
   - `game_logic.py`
   - `database.py`
   - `requirements.txt`
   - `.gitignore`
6. Внизу сторінки натисніть зелену кнопку **Commit changes**.

---

### Крок 2. Підключити до Render.com
1. Відкрийте [dashboard.render.com](https://dashboard.render.com).
2. Натисніть **Web Services** (кнопка `New Web Service ->`).
3. Оберіть свій репозиторій `pisun-bot` і натисніть **Connect**.
4. Заповніть прості поля:
   - **Name:** `pisun-bot`
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
   - **Instance Type:** обов'язково оберіть **Free** ($0/month).
5. Нижче знайдіть розділ **Environment Variables** (Змінні оточення), натисніть **Add Environment Variable**:
   - **Key:** `BOT_TOKEN`
   - **Value:** ваш токен від @BotFather
6. Натисніть кнопку **Create Web Service** внизу сторінки!

Через 1-2 хвилини Render встановить бібліотеки та запустить бота. Він працюватиме цілодобово 24/7, навіть якщо ви вимкнете свій комп'ютер!
